# Finanzas App

Finanzas is an SPA built with Next.js 16, React 19, and Tailwind CSS, designed for personal financial resource management. The application features user authentication—including registration, login, and logout—as well as route protection and automatic token renewal via an external API built with Spring Boot.

The system organizes its functionality into modules for accounts, categories, transactions, transfers, and budgets. Currently, account and category management is connected to the backend, supporting operations such as creation, editing, deletion or deactivation, pagination, validation, loading states, and error handling.

## Technologies | Tecnologías

- React 19
- Next.js 16
- Tailwind CSS
- Shadcn UI
- Turbopack
- Axios
- TanStack Query
